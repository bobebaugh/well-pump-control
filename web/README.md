# Web beta

Static HMI served by Netlify with same-origin function requests. Home shows live
observations and events; records.html browses durable evidence and exports CSV;
rules-engine.html authors, validates, backs up and publishes V3 configuration.
Owner actions use the shared password checked by server functions. Read-only
monitoring is public. See [BETA](../BETA.md) for the live-data boundary and release
workflow, [DESIGN](../DESIGN.md) for implemented behavior and [FUTURE](../FUTURE.md)
for deferred features. Do not use the legacy rules page as the V3 authoring guide.
