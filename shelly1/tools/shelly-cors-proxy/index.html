Play the pressure switch

Drives input:0 by flipping its invert config, which changes the state the Shelly reports and so produces the same rising and falling edge a real pressure switch would. The run timer starts on a fresh Activate; the elapsed value at Deactivate is what the script measures against its own MinRuntime.

Unverified on this device, and it writes persisted config. If Activate does not change Input(0) in the display above, the device does not produce an edge this way and the only route is a jumper at the SW terminal. invert is shown beside Input(0) so you always know whether it has been left flipped; Clear invert puts it back to false.

Play Tab5

With the real anti-chatter.js running, setting this true should open RLY0 within a second, and clearing it should close RLY0 provided IsLocked is 0. If Tab5 is running with a rules runtime it will revert this within a cycle or two — it reconciles the flag against its own ownership. Stop Tab5, or run it with no adopted package, to drive this by hand.
